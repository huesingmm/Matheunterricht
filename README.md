# Matheunterricht

Interaktive Unterrichtsmaterialien, veröffentlicht über GitHub Pages:
https://huesingmm.github.io/Matheunterricht/

## Aufbau

```
index.html           Startseite (EF, Q1, Sekundarstufe I)
assets/style.css     gemeinsames Design
assets/aufgaben.js   Aufgaben mit Sofort-Rückmeldung (Anleitung im Dateikopf)
ef/                  Einführungsphase, je Reihe ein Unterordner
q1/                  Qualifikationsphase 1, je Reihe ein Unterordner
sek1/                Sekundarstufe I
```

Eine neue Reihe bekommt einen eigenen Unterordner mit `index.html`,
z. B. `ef/funktionen/index.html`, und eine Kachel auf der Übersichtsseite der Stufe.
Ordnernamen bitte ohne Umlaute und Leerzeichen.
